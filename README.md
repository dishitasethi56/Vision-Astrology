# VISION — Astrology Website

A responsive, static HTML/CSS/JavaScript website for VISION, an astrology consultation practice based in Mumbai. Designed for GitHub Pages; no build tools or WordPress installation required.

## Files
- `index.html` — Home, About, Services and Contact sections
- `styles.css` — responsive styling and peacock-jewel colour palette
- `script.js` — mobile navigation and appointment enquiry form
- `assets/vision-logo.png` — supplied logo, cleaned and cropped
- `assets/peacock-art.jpg` — supplied peacock artwork

## Before publishing
1. Open `script.js`.
2. Replace `YOUR_EMAIL@example.com` with the astrologer's real email address.
3. Optionally add a WhatsApp number to `VISION_WHATSAPP` in international format, digits only (for example `919876543210`).
4. Commit and push the files to the repository's root.

The enquiry form opens the visitor's email app (or WhatsApp if configured). It does not store submissions on a server. For an online booking database, connect a booking/form service later.

## Publish with GitHub Pages
1. Open the repository's **Settings → Pages**.
2. Under **Build and deployment**, choose **Deploy from a branch**.
3. Select the branch containing these files (usually `main`) and folder `/ (root)`.
4. Save and wait for the Pages URL to become available.

## Notes
- The website intentionally avoids claims of guaranteed predictions or guaranteed remedies.
- Remedy copy explains that suggested stones/beads and activities are discussed where appropriate, and that VISION does not support black magic, harmful rituals or wrongdoing.
- No prices, phone numbers, testimonials or astrologer credentials have been invented.
